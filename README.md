# 剧匣更新仓库

这个仓库用于发布剧匣 Windows x64 安装包和版本说明，不包含软件源码、个人项目、素材或提示词。

## 更新测试

首次安装支持自动更新的 v0.8.3 后，可以在剧匣设置中检查新版本。收到更新提示后，选择“更新并重启”，软件会下载、校验并安装更新。

v0.8.3.1 用于验证更新流程，与 v0.8.3 功能一致。正式在线升级验收尚未完成。

## 发布要求

- 标签使用数字版本，例如 `v0.8.3.1`。
- 安装包名称使用 `Juxia-Setup-v0.8.3.1-x64.exe`，版本与标签一致。
- 上传完整安装包后再发布 Release，GitHub 生成的 SHA-256 digest 必须与本地一致。
- 主程序只接收已发布、非预发布、比当前版本更新的 x64 安装包。
- 请勿上传源码交接包、个人项目库或账号密钥。

[查看版本发布](https://github.com/wuqi01-del/juxia-updates/releases)
